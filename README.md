# advnotas-instagram

Imagens dos posts do Instagram do AdvNotas. O time de marketing sobe aqui os PNG de cada post depois da aprovação do Vitor, e o Buffer busca as imagens pelo link direto.

Uma pasta por post: `posts/<id do post>/slide-1.png`, `slide-2.png` e assim por diante.

Não guarde aqui nada que não vá ser publicado.
